# Squarebie

This project is a modification of the Starbie starter project. Since I wanted to make something original, I decided to go down a slightly different path to Starbie. I wanted to turn this into more of a mini computer, desk assistant and macropad rather than a virtual pet.

My plan is to have this Squarbie be used as a sort of second mini device that pairs with my computer. I plan to have an app where you can do things such as set timers, reminders, make the 3 buttons on it customizable macropad keys, and display custom animations on it. But I'll have to leave that for later as I need the board in person (I don't know how to do it without it) to make the app. But for now, it functions as its own mini computer, with a stopwatch, a counter, and a reaction time game, which is still fully functional.
